# Synthetic executable PolyCSS fixture

This tiny, redistributable fixture exercises the executable `domformat@0` /
`polycss-3d@0` playback, surface, effects, and presentation contracts. It has
one retained leaf, one surface state, one fixed effect-particle slot, and no
private producer data. The browser-decodable 2x2 PNG and CSS are original test
data.

It intentionally omits pointer interaction; the separate
`fixtures/synthetic-interaction` packet covers that codec's numeric kernel.
